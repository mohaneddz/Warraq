# Warraq identity assets

## Core assets

- `warraq-symbol.png` — full-color standalone mark with transparency
- `warraq-horizontal.png` — horizontal logo with transparency
- `warraq-symbol-ink.png` — monochrome dark mark
- `warraq-symbol-cream.png` — monochrome light mark
- `warraq-app-icon-dark-1024.png` — dark application icon master
- `warraq-app-icon-light-1024.png` — light application icon master
- `icon-512.png`, `icon-256.png`, `icon-128.png`, `icon-32.png` — ready-to-use sizes
- `warraq.ico` — multi-resolution Windows/Tauri icon
- `brand-tokens.json` — color, font, radius, and icon tokens

## Brand rules

- Primary colors: Ink `#17211F`, Emerald `#176B57`, Parchment `#F4EBDD`, Copper `#C87941`
- Latin typography: Manrope
- Arabic typography: IBM Plex Sans Arabic
- Keep clear space around the mark equal to roughly one quarter of its width.
- Prefer the full-color mark on parchment or ink backgrounds.
- Use monochrome variants only where color reproduction is unavailable.
- Do not rotate, stretch, recolor, outline, or add effects to the mark.
